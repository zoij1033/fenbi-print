1小书签方式（推荐✨·从 GitHub 加载）

下面这个按钮就是小书签。把它拖到浏览器书签栏（或右键 →「复制链接地址」后手动新建书签），以后打开粉笔做题页，点一下书签即可排版，面板会自动出现。

✨ 粉笔试卷排版打印

拖不动？右键按钮 →「复制链接地址」，再手动新建书签把地址粘进「网址」框。

适用浏览器：桌面版 Chrome / Edge / Firefox 都可以，Windows 和 Mac 都能用。
· Mac 用户：如果在 Safari 上用不了（粉笔题库在 Safari 里本身就容易显示不全），换 火狐 Firefox 或 Chrome / Edge 再试一次。
· 手机 / 平板：基本用不了，小书签很难触发，而且存 PDF 需要电脑上的打印对话框。
点一下书签，会自动从网络加载最新版（会先弹出一个带进度条的「加载中」提示，国内网络慢时稍等几秒属正常）。加载好后右下角会出现操作面板，以后每次点书签都是最新版，书签链接不用改。

2油猴脚本方式 功能一致·自动常驻

打开试卷页会自动出现面板，不用每次点书签。需要先装 Tampermonkey 扩展：

  1. 点下面的按钮去装 Tampermonkey（浏览器扩展商店页面，点「添加至浏览器」）
  2. 装完回到本页，点第二个按钮，在油猴的确认页点「安装」
① 去装 Tampermonkey ② 安装本脚本
适用浏览器：桌面版 Chrome / Edge / Firefox 装 Tampermonkey 扩展即可，Windows 和 Mac 都支持。
· Mac 用户：推荐用火狐 Firefox / Chrome / Edge 装 Tampermonkey；Safari 上如果装不了或用不了，就换火狐之类的浏览器试试。
· 手机 / 平板：不支持，手机浏览器装不了油猴扩展。
注意：浏览器不允许网页替你装扩展，这两步的「添加」和「安装」都必须你自己点一下。这不是本脚本的限制，是所有浏览器共同的安全规则。

4怎么用

  1. 打开粉笔的做题页（不是题库列表页），等题目完全加载出来
  2. 点一下小书签（油猴方式则面板自动出现）
  3. 右下角出现「试卷排版打印」面板 → 点排版并打印
  4. 在打印对话框里，目标选「另存为 PDF」，纸张 A4，边距选「默认」，务必勾选「背景图形」
  5. 同一对话框里取消勾选「页眉和页脚」，否则每页顶部会出现网页标题/网址，底部会出现日期

Mac 用户注意（打印面板长得不一样）：Mac 的打印面板里没有「目标」这一栏——请点面板左下角的 「PDF」按钮 → 选「存储为 PDF」；再点「显示详细信息」取消勾选「页眉和页脚」。纸张选 A4 即可。「背景图形」脚本已强制开启，Safari 里没有这个勾选框也不影响输出。

面板里点「设置」可调字号、行距、页边距、分页策略、申论作答区等；设置会被记住，面板也能拖动。

5常见问题

点了书签没反应？
点完后屏幕中央会先出现一个「粉笔打印脚本加载中…」浮层（带进度条和已等待秒数），这是正常的——它在并行从 GitHub / jsDelivr 拉脚本，国内网络慢时可能要等几秒到十几秒。若浮层一直停在「正在并行连接多个源…」并最终变成「三个源均不可达」，说明你的网络连不上 GitHub 和 jsDelivr（可改用国内 CloudBase 镜像源，见上）；若浮层消失却仍无面板，按 F12 看控制台报错，CORS 报错通常是托管服务没配跨域头。

提示「没有找到题目」？
请确认进的是做题页且题目已全部渲染出来；申论页脚本会逐个切换材料与题目标签抓取，需要等十几秒。

导出的 PDF 里图形题是空白？
图片来自粉笔服务器，需要联网。想彻底离线，先联网打开一次并打印成 PDF。

每页后面都多一个空白页？
旧版按固定 15mm 边距算每页高度，但 Chrome 打印对话框「默认」边距约 20mm，可打印区被压得更小，每页溢出几像素就被强制多分一页空白。v1.6.0 已改成「整张 A4 钉死 + 内部 padding 留白」，无论对话框边距选「默认 / 最小 / 无」都正好一页一页、不再多空白。仍出现就确认自己装的是 v1.6.0 及以上（小书签需换 @main 或新 commit 才能拿到）。

PDF 顶部/底部有标题、网址、日期？
那不是脚本生成的，是浏览器打印对话框默认勾选了「页眉和页脚」。在打印设置里取消勾选即可，脚本无法代你关闭。

封面后面多了一页空白？
你勾了面板里的「附自制封面页」，它会自动加一页缓冲页。不想要就取消勾选封面。
